## Česky
Aplikace "AI agenti VPS" je soukromý nástroj provozovatele. Slouží výhradně k tomu, aby jeho vlastní AI agenti (běžící na jeho soukromém serveru) mohli pracovat s daty jeho vlastního Google účtu: Kalendář, Disk, Dokumenty, Tabulky a Gmail.

- Aplikaci používá pouze provozovatel se svým vlastním účtem. Není určena veřejnosti.
- Data z Google služeb se zpracovávají jen na soukromém serveru provozovatele a nejsou předávána třetím stranám, prodávána ani využívána k reklamě.
- Přístupové tokeny jsou uloženy pouze na tomto serveru a lze je kdykoli odvolat v nastavení Google účtu (Zabezpečení, Aplikace třetích stran).
- Použití údajů z Google API se řídí zásadami Google API Services User Data Policy včetně požadavků Limited Use.

## English
"AI agenti VPS" is a private tool of its operator. Its only purpose is to let the operator's own AI agents (running on the operator's private server) work with data of the operator's own Google account: Calendar, Drive, Docs, Sheets and Gmail.

- The app is used solely by the operator with their own account. It is not offered to the public.
- Google data is processed only on the operator's private server and is never shared with third parties, sold, or used for advertising.
- Access tokens are stored only on that server and can be revoked at any time in Google Account settings (Security, Third-party apps).
- Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
